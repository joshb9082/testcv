# Personal Website Repository

This repository contains a simple personal website. The main entry point is
`index.html`, which introduces the site and links to other pages. There is also
a **Contact Me** page (`contact me.html`) where visitors can send messages or
find your contact information.

## Viewing Locally

Clone or download this repository and open `index.html` in your web browser.
You can simply double-click the file or serve it through a local web server to
view the site.
